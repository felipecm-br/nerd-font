# JetBrainsMono Nerd Font Propo

Mirror of the four `JetBrainsMono Nerd Font Propo` styles (Regular, Bold, Italic, BoldItalic), v3.5.1 from the Arch `ttf-jetbrains-mono-nerd` package.

Licensed under OFL-1.1 (see `OFL.txt`). Upstream: https://github.com/ryanoasis/nerd-fonts

## Install (Linux)

```sh
git clone https://github.com/felipecm-br/nerd-font.git
mkdir -p ~/.local/share/fonts
cp nerd-font/*.ttf ~/.local/share/fonts/
fc-cache -f
```
